# Fixture Admin Guide

## 1 Users

### 1.1 Create user
Only an Admin can create a user. An Admin opens My account, chooses Create user, enters an email and
saves. A Viewer must not see the Create user page or its link.

### 1.2 Team page
Managers and Admins can open the Team page from My account. A Viewer cannot.

## 2 Billing

### 2.1 Export invoices to PDF
An Admin can export every invoice to one PDF file from the Invoices page with the Export all to PDF button.
