The sign-in form sends passwords in the page address

The form uses GET (or names a page to send to with no method, which means GET), so the password goes into the address

Suggested Fix: Send the form with method="post". A password in the address is kept in browser history, server and proxy logs, and analytics, and can leak to other sites through the Referer header.
