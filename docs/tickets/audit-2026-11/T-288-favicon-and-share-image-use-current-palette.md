## Problem

T-202 moved the manifest and `index.html` to the Certificate palette (`#F4F6F4` paper) but left the favicon and the share image on the old dark-blue palette (`#111827` and a light-blue `#6C9BF2`). The tab icon and the link preview no longer match the app.

## Owner decision needed

T-202 asked for design sign-off. Options for the colours:

- A. The dark palette from `packages/wizard/DESIGN.md` ("Colour" table, dark column): paper `#0E1311`, stamp `#8FA6FF`, ink `#E8EEEA`, ink-soft `#A8B4AE`. Keeps the dark look, uses only tokens. **Recommended default.**
- B. The light palette (paper `#F4F6F4`, stamp `#1D3FD0`, ink `#121A17`). Matches the manifest colour exactly.

This ticket writes option A. For B, swap the values in the table below.

## Tests

In `packages/wizard/tests/share-image.test.ts`, add inside `describe('share image'`:

```ts
it('favicon and the image script use palette colours, not the old dark blue', () => {
  const favicon = readFileSync(join(WIZARD, 'public', 'favicon.svg'), 'utf8');
  const script = readFileSync(join(WIZARD, 'scripts', 'make-og-image.mjs'), 'utf8');
  for (const old of ['#111827', '#6C9BF2', '#9ca3af', '#f9fafb', '#d1d5db']) {
    expect(favicon.toLowerCase()).not.toContain(old.toLowerCase());
    expect(script.toLowerCase()).not.toContain(old.toLowerCase());
  }
  expect(favicon).toContain('#0E1311');
  expect(favicon).toContain('#8FA6FF');
  expect(script).toContain('#0E1311');
});
```

The existing test `og-image.png is a 1200x630 PNG` must still pass (file under 500 KB).

Run: `pnpm exec vitest run packages/wizard/tests/share-image.test.ts packages/wizard/tests/title-robots.test.ts`.
