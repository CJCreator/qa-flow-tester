# 0013: Opt-in AI Explorer and AI-Proposed Selector Fixes

Status: Deferred. No decision has been made and nothing is built. This number is kept so the roadmap's references (gap G22, self-healing, item 3.1 in `docs/E2E_PLATFORM_IMPLEMENTATION_PLAN.md`) resolve. It amends [0009](0009-ai-plans-every-plan-item.md) if accepted.

## Context and Decision
The roadmap asks for two things that would change what the AI may do: an opt-in AI explorer that walks a site beyond the crawl, and AI-proposed fixes for selectors that broke, saved as Plan changes for the person to review. Neither is in the code. Until this record is accepted, the AI plans only from what the crawl found ([0009](0009-ai-plans-every-plan-item.md), [0011](0011-ai-asked-only-what-facts-cannot-say.md)), and no selector is rewritten.

## Consequences
- A proposal for either feature needs this record accepted first, with its safety rules (who opts in, what is sent to the AI, how a fix is reviewed).
- Nothing in the product depends on this number yet.
